# 준공 이관검사 시스템 (Transfer Inspection System)

공동주택 도어록(DDL)·홈네트워크(HN/HA) 준공 이관검사의 **신청 → 검토승인 → 1차 판정 → 최종 판정 → 결과 통보** 전 과정을 다루는 단일 페이지 프로토타입입니다.

## 데모

https://kimsoungryoul.github.io/transfer-inspection-system/

## 화면 구성

| 역할 | 화면 | 내용 |
| --- | --- | --- |
| 공통 | 로그인 / 회원가입 | 신청자·감독관 역할 선택, 소셜 로그인 목업 |
| 이관검사 신청자 | 내 신청 현황 | KPI, 방문 일정 카드, 신청 목록, 상세 타임라인 |
| 이관검사 신청자 | 이관검사 신청 | 제품군 선택 후 4단계 폼 (현장 기본정보 · 설치점/담당자 · 제품 정보 · 보증/검사요청) |
| 감독관 | 신청 접수 목록 | 필터·정렬·일괄 검토승인·엑셀 내보내기 목업 |
| 감독관 | 방문 캘린더 | 월간 방문예정일 캘린더, 일자별 방문 동선 |
| 감독관 | 판정 대기 | 1차·최종 합불 판정 입력, 하자이행증권 확인, 결과 통보 |

- 검사 양식은 DDL 41개 항목 / HN·HA 58개 항목 기준입니다.
- 현장 위치 지정은 [Leaflet](https://leafletjs.com) + [OpenStreetMap](https://www.openstreetmap.org) 타일과
  [Nominatim](https://nominatim.openstreetmap.org) 지오코딩을 사용합니다.

## 반응형

데스크톱 레이아웃을 유지하면서 태블릿·모바일까지 대응합니다. 화면이 좁아지는 순서대로:

| 분기점 | 달라지는 것 |
| --- | --- |
| ~1180px | 고정 최소폭(1180px) 해제, 6·5열 입력 그리드를 3열로 |
| ~1024px | 상세 화면 2단 → 1단, 판정 패널 sticky 해제, 4열 그리드를 3열로 |
| ~900px | 좌측 메뉴가 햄버거 오프캔버스 드로어로 전환, 상단바에서 알림·소속 표기 제거 |
| ~720px | 전 영역 1단(정보 그리드는 2단 유지), KPI 2열, 지도·계정 선택 모달은 바텀시트, 우측 드로어 전체폭 |
| ~560px | 상단바 제목 숨김, KPI·소개 지표 단일 열 |

- 목록 표는 모바일에서 우선순위가 낮은 열(원청·현장PM·수량·신청일 등)을 숨기고 나머지는 가로 스크롤합니다.
- 방문 캘린더는 7열 격자를 유지한 채 가로 스크롤합니다.
- 모바일에서 입력 요소는 16px로 렌더링해 iOS 사파리의 포커스 자동 확대를 막습니다.
- 뷰포트 높이는 `100dvh`를 사용해 모바일 브라우저 주소창 높이 변화에 대응합니다.

## 데이터에 대한 안내

화면에 보이는 **현장명, 회사명, 담당자명, 연락처, 이메일, 프로젝트 코드, 제품 모델명, 증권번호는 모두 가상의 더미 데이터**입니다.
실제 사업장·기업·개인 정보와는 무관하며, 우연히 일치하더라도 의도된 것이 아닙니다.

## 실행

정적 파일 하나로 끝나는 구조라 서버가 필요 없습니다.

```bash
# 브라우저로 바로 열기
open index.html

# 또는 로컬 서버로
python3 -m http.server 8000
```

지도 타일과 주소 검색만 외부 네트워크(OpenStreetMap)를 사용하고,
React·Leaflet·웹폰트를 포함한 나머지 자산은 모두 `index.html` 안에 인라인으로 번들되어 있습니다.

## 기술

- React 18 (UMD, 인라인 번들)
- Leaflet 1.9.4
- Noto Sans KR / Roboto Mono (woff2 서브셋 인라인)
- 빌드 도구·의존성 설치 없음
- 반응형은 인라인 스타일 위에 얹은 미디어쿼리 레이어(`ti-` 접두사 클래스)로 처리
